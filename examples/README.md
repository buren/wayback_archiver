# Examples

Runnable scripts demonstrating common WaybackArchiver use cases.

| Example | Description |
|---------|-------------|
| [basic.rb](basic.rb) | Single URL archiving, inspecting results |
| [bulk.rb](bulk.rb) | Archiving a list of URLs in parallel |
| [sitemap.rb](sitemap.rb) | Sitemap-based archiving with limit |
| [crawl.rb](crawl.rb) | Crawling a site for URLs |
| [rss_feed.rb](rss_feed.rb) | Archiving from an RSS/Atom feed |
| [streaming_results.rb](streaming_results.rb) | Using a block for progress reporting |
| [track_outlinks.rb](track_outlinks.rb) | Manually polling outlink job IDs |
| [screenshots.rb](screenshots.rb) | Downloading screenshots of archived pages |
| [report.rb](report.rb) | Writing CSV and JSON report files |
| [event_listener.rb](event_listener.rb) | Event listeners for progress, errors, and lifecycle hooks |
| [custom_adapter.rb](custom_adapter.rb) | Lambda and class-based custom adapters |
| [file_input.sh](file_input.sh) | Reading URLs from a file or stdin |
| [two_phase.sh](two_phase.sh) | Discover URLs first, then archive separately |
